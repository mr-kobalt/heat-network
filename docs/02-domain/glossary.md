# Глоссарий и соответствие коду

Документация — на русском, идентификаторы в коде — на английском.
Таблица задаёт единое соответствие, чтобы команда и AI-агенты не вводили
синонимов. При добавлении новых терминов дополняйте таблицу.

## 1. Предметные термины

| Русский | Англ. / код | Определение / значение в системе |
|---------|-------------|----------------------------------|
| ОКС | `OKS`, `oks` | Объект капитального строительства; полигон — `restriction` с `restriction_type=oks` |
| Точка подключения ОКС | `oks_connection_point` | Точка подключения со своим `flow_tph`; самостоятельная цель |
| ИТП | `ITP` | Индивидуальный тепловой пункт (внутри здания, не моделируется) |
| Источник теплоснабжения | `source` | Теплоисточник (например, ТЭЦ) |
| Тепловая сеть | `heat_network` | Совокупность трубопроводов |
| Участок сети | `heat_network`, segment | Линейный объект (`LineString`), пара труб одного Ду |
| Тепловая камера | `heat_chamber` | Подземное сооружение с оборудованием и соединениями |
| Технический узел | `technical_node` | Служебная точка смены параметра без разветвления; без стоимости |
| Присоединение | tie-in | Присоединение новой сети через камеру; отдельного объекта `tie_in` нет |
| Единый лес | unified forest | Алгоритм `grid-forest` (ADR-0034): поиск по сетке от существующей сети, общие стволы; один план, несколько деревьев |
| Маска запретов | `ObstacleMask` | Консервативная растровая маска запретных зон (ADR-0033) для быстрого отсева рёбер; ячейка — наименьшая ширина пары труб |
| Сетка поиска | grid | Пространство поиска пути (ADR-0034): консервативная проходимость клеток, многоисточниковый Дейкстра от сети |
| Врезка в существующую камеру | `existing_chamber_tie_in` | 5 000 000 руб. за каждый новый участок, заканчивающийся в камере |
| Примыкание | attachment | Линейный участок, геометрически заканчивающийся в камере; ≤4 на камеру |
| Проходная линия | through line | Существующая линия через камеру; занимает 2 примыкания |
| Условный диаметр (Ду) | `diameter`, `DN` | Типовой размер трубопровода, мм |
| Расход | `flow_tph` | Расчётный расход, т/ч |
| Пропускная способность | capacity | Максимальный расход для Ду, т/ч |
| Предельная длина | max length | Макс. длина непрерывной части одного Ду, м |
| Прокладка бесканальная | ductless laying | Трубы непосредственно в грунте (базовый способ) |
| Способ прокладки | `laying_method` | `base` (обычная) или `special` (специальный проход) |
| Специальный проход | special crossing | Участок прохождения ограничения с особыми условиями |
| Коэффициент спецпрохода | `Kспец` / `kSpecial` | Множитель стоимости спецучастка |
| Коэффициент глубины | `Kгл` / `kDepth` | Множитель стоимости при заглублении > 3,0 м |
| Расчётный габарит | design gauge | Прямоугольник пары труб (ширина × высота) |
| Пространственное ограничение | `restriction` | Объект, влияющий на трассу |
| Тип ограничения | `restriction_type` | Обязательные: `oks`, `park`, `social_area`, `prohibited_site`, `water`, `railway`, `road`, `tram_tracks`, `gas_pipeline`, `power_cable`, `heat_network`; прочие — расширение |
| Финальный участок | final approach segment | Один прямой участок от ближайшей границы `oks`-полигона до точки подключения |
| Точка выхода ОКС | `ConnectionExit`, `target` | Каноническая точка стыковки за внешней границей буфера ОКС (ADR-0032); `tail` — финальный отрезок `[target, точка]` |
| Вариант | `variant` | Решение подключения; `variant_id` |
| Сводка варианта | `variant_summary` | Итоговые показатели варианта |
| Показатель ранжирования | `score`, `S` | `0.7·(C/25e6) + 0.3·(L/100)` |
| Неподключённые ОКС | `unconnected_oks_ids` | Перечень ID ОКС без маршрута |
| Штраф за неподключение | unconnected penalty | `100e6 + 500000·G` |
| Ось препятствия | obstacle axis | Осевая линия объекта для отсчёта угла пересечения; строит команда (протокол) |
| Спецучасток | special segment | Часть участка, проходящая ограничение по правилам спецпрохода |
| Максимальный коэффициент | max coefficient | При наложении спецпроходов берётся максимум `Kспец`, без суммирования и перемножения (ТП 4) |
| Угол поворота | turn angle | От продолжения предыдущего участка; 0° — прямая, допускается до 90°; без удорожания (ТП 2.1) |
| Сервис без UI | headless service | Чистый сервис «входные данные → GeoJSON»; UI не требуется (протокол) |

## 2. Соглашения об именовании в коде

- Пакеты: `ru.lct.heating.<module>` (см. `package-info.java`).
- Классы: `PascalCase` (`HeatNetwork`, `DiameterTable`, `RoutePlanner`).
- Методы/поля: `camelCase` (`selectDiameter`, `flowTph`).
- Константы: `UPPER_SNAKE_CASE`.
- Сущности предметной области — иммутабельные где возможно (`record` в Java 11
  недоступен; используем неизменяемые классы или Lombok `@Value`).
- Денежные величины — `long`/`BigDecimal`? Решение — ADR-0005: `double` для
  геометрии и промежуточных расчётов, округление перед выводом.
