# Глоссарий и соответствие коду

Документация — на русском, идентификаторы в коде — на английском.
Таблица задаёт единое соответствие, чтобы команда и AI-агенты не вводили
синонимов. При добавлении новых терминов дополняйте таблицу.

## 2. Соглашения об именовании в коде

- Пакеты: `ru.lct.heating.<module>` (см. `package-info.java`).
- Классы: `PascalCase` (`HeatNetwork`, `DiameterTable`, `RoutePlanner`).
- Методы/поля: `camelCase` (`selectDiameter`, `flowTph`).
- Константы: `UPPER_SNAKE_CASE`.
- Сущности предметной области — иммутабельные где возможно (`record` в Java 11
  недоступен; используем неизменяемые классы или Lombok `@Value`).
- Денежные величины — `long`/`BigDecimal`? Решение — ADR-0005: `double` для
  геометрии и промежуточных расчётов, округление перед выводом.
