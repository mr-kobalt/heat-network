# Скриншоты визуализатора

Изображения для пояснительной записки и презентации. Открываются в разделе
«Документация» визуализатора (резолвер ассетов, ADR-0075) и на GitHub.

## Файлы

| Файл | Что показать |
|------|--------------|
| `map-2d.png` | Карта: вход (ОКС, существующая сеть) + результат (новая сеть, камеры), легенда, режим **2D** |
| `details-summary.png` | Попап участка (Ду, длина, стоимость, `depth_*`) и/или сводная таблица вариантов |
| `stages-depth.png` | Пример работы алгоритма: вкладки этапов (`Деревья`, `relink`, `refine`) либо режим **Глубина** |

## Как снять

1. Поднять стек: `make dev` (или `make fe-up`).
2. `make run` / загрузить `source/Датасет скорректированный.geojson`, режим
   `2D`, при необходимости включить трассировку этапов.
3. Снять 2–3 кадра в браузере (окно ~1600×1000), сохранить под именами выше.

> Изображения — часть пояснительных материалов; в оцениваемую поставку
> (headless-сервис) не входят.
