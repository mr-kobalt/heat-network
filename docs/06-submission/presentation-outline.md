# Презентация (структура и сборка)

Единый источник презентации — **[presentation.md](presentation.md)**
(Markdown, ~20 слайдов, заметки спикера). Файл `.pptx` собирается через
pandoc с темой организатора (шрифт **Montserrat**, палитра ЛЦТ 2026).

```bash
make presentation
# → target/presentation/sudoers-lct2026.pptx
```

Сборка: `pandoc` генерирует базовый `reference.pptx` (локально, из своего
дистрибутива), скрипт `scripts/build-presentation-reference.py` применяет тему
организатора (`#FF0053`, `#310F53` и др.), затем pandoc собирает `.pptx`
(`#` = слайд, `::: notes` = заметки спикера).
