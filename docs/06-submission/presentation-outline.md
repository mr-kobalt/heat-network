# Презентация (структура и сборка)

Единый источник презентации — **[presentation.md](presentation.md)**
(Markdown, ~20 слайдов + разделители, заметки спикера). Сборка — в **PDF**
(основной формат) с темой организатора: шрифт **Montserrat**, палитра ЛЦТ 2026
(`#FF0053`, `#310F53`, `#FFD6E4`) и декоративные плашки.

```bash
make presentation          # → target/presentation/sudoers-lct2026.pdf
make presentation-notes    # + PDF с заметками спикера
make presentation-pptx     # запасной формат pptx (pandoc)
make presentation-all      # PDF + notes + pptx
```

Сборка (`scripts/build-presentation.mjs`): `pandoc` собирает HTML
(`--section-divs`, один `#` = слайд, `::: notes` = заметки), затем **Chromium**
печатает PDF (`@page` 13,333×7,5 in, без колонтитулов). Тема — 
[presentation-theme.css](presentation-theme.css) (шрифты —
`presentation-assets/fonts/`, OFL-1.1). Вариант с заметками подключает
`presentation-theme-notes.css` (страница выше, слайд «резиновый»).
