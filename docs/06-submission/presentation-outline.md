# Структура презентации

Черновик содержания защиты. Оформление — по шаблону организатора
(`source/ЛЦТ2026 Шаблон презентации.pptx`: шрифт Montserrat, заданные цвета,
логотипы постановщика задачи). Требования к оформлению публикуются в личном
кабинете (раздел «Хакатон»).

## Слайд 1. Титул

- Название команды; название задачи (трек «Тепловые сети / ОКС»).
- Номер и название задачи, логотип постановщика.

## Слайд 2. Команда

- Состав, роли, город/регион, контакты (роль, мессенджер, телефон).
- Краткое описание: как собрались, релевантный опыт.

## Слайд 3. Задача и проблема

- Плотная городская застройка, тысячи объектов, ручной подбор трасс — долго и
  неоптимально.
- Что автоматизируем: врезка через камеры, общие стволы, ограничения, Ду+длина,
  стоимость, до трёх вариантов.

## Слайд 4. Решение — что делает сервис

- Вход: один GeoJSON. Выход: GeoJSON с вариантами и сводками.
- Headless, офлайн, REST + Swagger; воспроизводимый расчёт.

## Слайд 5. Техническая суть (1): алгоритм

- `grid-forest`: сетка проходимости → рост леса → relink/refine → камеры.
- Точный подбор Ду и стоимости; эвристика маршрутизации.
- Диаграмма конвейера (см. [algorithm.md](../03-architecture/algorithm.md)).

## Слайд 6. Техническая суть (2): стек и качество

- Java 11 / Spring Boot 2.6.3 / Maven / PostgreSQL + PostGIS / Spring Data.
- Потоковая обработка (вход до 3 ГБ), партиционирование.
- Инварианты ТП v2 в тестах; эталонные прогоны (baseline).

## Слайд 7. Соответствие обязательным правилам

- Присоединение через камеру, ≤4 примыканий, проходная линия = 2.
- Ду + предельная длина по непрерывным путям.
- Спецпроходы, финальный участок в `oks`, стоимость и `S`, до трёх вариантов.
- Реконструкция не выполняется (ТП v2).

## Слайд 8. Демонстрация

- Прогон на наборе: результат GeoJSON, карта (опциональный визуализатор),
  промежуточные этапы.
- Частичный результат и диагностика.

## Слайд 9. Уникальность и эффективность

- Конфигурируемые правила ограничений (ADR-0009), универсальность (NFR-09).
- Показатель `S`, прозрачное ранжирование вариантов.
- Дополнительный режим глубины (M4).
- Время расчёта и масштабируемость.

## Слайд 10. Планы развития

- Интеграция глубины в поиск пути (E9-05), PostGIS-спилл сетки.
- Расширение проверочных наборов, дообучение эвристик.
