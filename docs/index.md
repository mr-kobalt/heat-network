## Принципы ведения документации

- Документация — часть Definition of Done.
- Один факт — в одном месте; остальные ссылаются.
- Изменение правил/форматов/алгоритмов отражается в соответствующих файлах.
- Архитектурные решения — только через ADR.
- Каждый изменённый документ ведёт раздел «История изменений» с датой и
  основанием (например, протокол встречи).
- При расхождении ТП и протокола встречи приоритет — за уточнениями
  организатора (протоколом).
