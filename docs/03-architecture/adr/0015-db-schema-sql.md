# ADR-0015. Управление схемой БД в M1: schema.sql

- Статус: accepted
- Дата: 2026-09-16

## Контекст

Согласно ADR-0005 Flyway не используется из-за несовместимости версии из
Spring Boot 2.6.3 с PostgreSQL 18. Начиная с M1 требуется PostgreSQL для
хранения метаданных датасетов и расчётов.

## Решение

Схему создавать идемпотентным `schema.sql` (`CREATE TABLE IF NOT EXISTS`),
выполняемым Spring Boot (`spring.sql.init.mode=always`). JPA используется
в режиме `ddl-auto=none` (схема не изменяется приложением). Хранение
геометрии и больших данных — в файлах рабочего каталога; в БД — метаданные,
статусы, диагностика и сводки (текст/JSON).

## Следствия

- Положительные: совместимость с PostgreSQL 18, отсутствие тяжёлых миграций,
  прозрачная схема.
- Отрицательные: нет версионирования миграций; при росте схемы потребуется
  пересмотр (например, проверенная версия Flyway/Liquibase на совместимом
  стеке). `ddl-auto=none` означает ручную синхронизацию сущностей и схемы.
