# ADR-0019. Лес маршрутизации: кластеризация и общие стволы

- Статус: accepted, уточнён ADR-0021 (ТП v2: присоединение через камеру,
  примыкания, без `tie_in`)
- Дата: 2026-09-19

## Контекст

В M1 каждая точка подключения маршрутизировалась независимо
(`RoutePlanner`): маршруты не делили общие участки, ветвления и камеры не
моделировались, расход на общих частях не суммировался. M2 (FR-23, FR-24,
FR-25, FR-41) требует совместного подключения ОКС, общих стволов, ветвлений
в камерах и распространения расхода по дереву. Задача «ограниченный лес
Штейнера» NP-сложна (см. `algorithm.md`), нужен детерминированный эвристический
подход.

## Решение

1. **Кластеризация ОКС.** Точки подключения объединяются в кластеры
   (single-linkage, радиус `cluster-radius-m`, конфигурируемо). Каждый кластер
   подключается к сети собственной врезкой, что не даёт длинных межгородских
   стволов.
2. **Остовное дерево.** Внутри кластера строится минимальное остовное дерево
   (MST, Прим) по евклидову расстоянию между точками подключения. Рёбра MST —
   потенциальные общие стволы: ребро обслуживает всё поддерево «ниже» себя.
3. **Врезка.** Корень дерева (точка кластера, ближайшая к сети) соединяется с
   сетью через лучший по стоимости кандидат врезки (`TieInCandidate`): среди
   ближайших кандидатов выбирается минимизирующий
   `длина · стоимость(Ду ствола) + стоимость врезки + стоимость камеры`.
4. **Узлы.** Типы узлов: `TIE_IN` (врезка в сеть/существующую камеру),
   `CHAMBER` (новая камера), `TECHNICAL_NODE` (смена Ду/способа прокладки),
   `CONNECTION_POINT` (точка подключения ОКС). Ветвление — узел с числом
   новых лучей ≥3; там обязательна камера (FR-25).
5. **Степень ≤4.** Узел камеры допускает 1 луч к источнику + ≤3 других
   (FR-26). При превышении создаётся дополнительная камера-разветвитель и
   лишние лучи переносятся на неё (эвристика).
6. **Потоки.** После построения дерева расход каждого ребра — сумма расходов
   ОКС его поддерева (`flow_tph`, пара труб считается одним расходом, FR-42).
7. **Геометрия.** Рёбра маршрутизируются существующим
   `VisibilityGraphRouter` (обход запретных зон). После построения выполняется
   упрощение (удаление повторных и коллинеарных вершин), исключаются
   самопересечения.
8. **Частичный результат.** Неудача маршрутизации ребра/кластера изолируется:
   соответствующие ОКС попадают в `unconnected_oks_ids` (FR-77).

Эвристика детерминирована (сортировки по id, фиксированный порядок обхода).

## Следствия

- Положительные: общие стволы и камеры появляются естественно; расход и
  стоимость согласованы; модель расширяема (реконструкция, варианты).
- Отрицательные: MST по евклидову расстоянию не учитывает препятствия при
  выборе топологии (маршрутизация рёбер — с обходом); качество стволов
  эвристическое. Степень ≤4 и объединение близких пересечений — приближённые.
