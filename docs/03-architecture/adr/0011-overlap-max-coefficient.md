# ADR-0011. Наложение ограничений: максимум коэффициента, один спецучасток

- Статус: accepted (ждёт окончательного подтверждения организатором, NQ-04)
- Дата: 2026-09-16

## Контекст

При прохождении трассы зоны нескольких пространственных ограничений могут
накладываться. ТП задаёт `Kспец` по каждому типу, но не описывает случай
наложения. Протокол встречи 16.09.2026 уточняет правило.

## Решение

При наложении зон нескольких препятствий:
- применяется **максимальный** `Kспец` из вовлечённых типов;
- выделяется **один** специальный участок на весь участок наложения;
- коэффициенты **не перемножаются**.

Правило реализуется в конфигурируемом виде (ADR-0009), чтобы при
окончательном ответе организатора изменить поведение без правки логики.

## Следствия

- Положительные: детерминированная и объяснимая стоимость; отсутствие
  неконтролируемого роста цены при наложении.
- Отрицательные: правило не финально; требуется подтверждение. Геометрия
  объединённого спецучастка должна строиться корректно (границы, углы).
