# ADR-0043. relink — топология, refine — углы маршрута

- Статус: accepted
- Дата: 2026-09-22

## Контекст

`relink` проверял угол в точке врезки (`incoming→candidate→target`), из-за чего
отвергал топологически выгодные привязки: например, точки 1 и 2 не сводились на
одну камеру. По принципу разделения ответственности `relink` должен решать
топологию (место врезки, обход запретов/пересечений), а геометрию маршрута
(повороты ≤90°, FR-34) — `refine`.

## Решение

1. **relink** (`TerminalRelinker.validSegment`): убран угловой контроль входа в
   кандидата (`incoming`). Сохранены проверки запретов и самопересечений, а также
   угол **стыка финального вывода** `target→point`: хвост задаётся резолвером
   (ТП 2.2) и `refine` его не меняет, поэтому стык контролируется в relink.
2. **refine** (`GridForestPlanner`) — владелец углов маршрута:
   - существующее string pulling и ремонт поворотов внутри ребра;
   - **ремонт углов в узлах**: для каждой пары инцидентных рёбер (включая
     «ветка↔ветка») при повороте > `forest-max-turn-deg` соседний сегмент
     перетрассируется turn-aware поиском по сетке (состояние «клетка +
     направление», ≤90° на каждом шаге, обход запретов) — `rerouteAtNode`/`gridPath`;
   - **ремонт подхода к выходу**: сегмент `prev→target` перетрассируется с
     конечным направлением под хвост `target→point` (если стык >90);
   - нерешаемое фиксируется предупреждением `FOREST_TURN_UNRESOLVED`.

Проверено: вариант «совсем без угловых проверок в relink» даёт `S` 13.365, но
7 итоговых поворотов >90 на стыках вывода (недопустимо, `refine` стык не меняет)
— отклонён. Оставлен контроль стыка вывода.

## Следствия

- Положительные: `S` 14.321 → **14.153**, длина 2071.8 → **2054.1 м**, стоимость
  289.48 → **285.39 млн**, камеры 56 млн; точки 1 и 2 сводятся на одну камеру
  (`br_0_11`); итоговых поворотов >90 — 3 (≤6).
- Ограничение: остаются диагностические `FOREST_TURN_UNRESOLVED: узел …` —
  повороты в стыках рёбер, которые раньше не проверялись вовсе; локальный
  reroute чинит не все (крупные углы/стеснения). Это предмет отдельной работы.
- Затрагивает `TerminalRelinker`, `GridForestPlanner` (refine: `repairNodeTurns`,
  `rerouteAtNode`, `gridPath`, `repairExitApproach`), тесты (baseline slow).
