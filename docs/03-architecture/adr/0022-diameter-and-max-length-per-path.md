# ADR-0022. Выбор Ду и предельной длины по непрерывным путям

- Статус: accepted
- Дата: 2026-09-19

## Контекст

ТП v2 §2.3 и разъяснения 1–2 меняют правила гидравлики относительно прежней
редакции M2:

- Ду выбирается **минимальным, одновременно удовлетворяющим** расчётному расходу
  и предельной длине (прежнее правило «+1 номенклатура» не применяется);
- предельная длина проверяется **по каждому непрерывному пути**; общий участок
  учитывается в каждом пути; длины параллельных ветвей **не суммируются**
  (прежняя реализация суммировала длины всех ветвей одной номенклатуры);
- выбранный Ду сохраняется на пути между узлами, где меняется расход; менять Ду
  только для нового отсчёта длины нельзя;
- Ду от точки подключения к месту присоединения не уменьшается.

## Решение

1. Поток на ребре — сумма расходов точек в поддереве (без изменений).
2. Базовый Ду ребра — минимальный по расходу; затем для каждого непрерывного
   пути проверяется суммарная длина участков одного Ду, и при превышении Ду
   повышается до следующего минимального, удовлетворяющего и расходу, и длине.
3. Общий участок учитывается в каждом пути; параллельные ветви не суммируются.
4. Смена Ду начинает новый отсчёт; узел/камера без смены Ду — нет.
5. Результирующий Ду не убывает от точки подключения к присоединению.

## Следствия

- Положительные: точное соответствие ТП v2; предельная длина не зависит от числа
  параллельных ветвей.
- Отрицательные: `MaxLengthEnforcer` переписывается на путь-ориентированный;
  возможен рост Ду более чем на одну номенклатуру (разрешено v2), но не
  произвольно — условие «минимальный подходящий» сохраняется.
