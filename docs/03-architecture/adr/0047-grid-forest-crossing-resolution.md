# ADR-0047. Разрешение самопересечений `grid-forest` средствами сетки

- Статус: accepted (E27, FR-29; реализовано 2026-09-23)
- Дата: 2026-09-23

## Контекст

`RouteCrossingResolver` (пересечения рёбер вне общих узлов, FR-29) подключён
только в legacy `mst`. Дефолтный `grid-forest` его не использует. На основном
наборе пересечений сейчас нет (`GridForestInvariantsSlowTest`: 0), однако
инвариант не гарантирован на произвольном наборе.

## Решение (предлагаемое)

Переписать разрешение пересечений под сетку, не переиспользуя
`RouteCrossingResolver`:

1. **Детектор** пересечений пар рёбер дерева во внутренних точках (общие узлы
   исключаются).
2. **Перепроложение «жертвы»** по сетке: снять одно ребро наименьшего вклада в
   `S` и перепроложить его, добавив остальные рёбра дерева временными
   препятствиями с вырезами вокруг общих узлов.
3. **Альтернатива** — перенос поддерева к другому узлу/T-врезке через
   `TerminalRelinker` (ADR-0044), если это дешевле.
4. После перестройки — пересчёт расходов/Ду/предельной длины
   (`MaxLengthEnforcer`), проверка углов ≤90° (`refine`) и степени ≤4.
5. **Инвариантный slow-тест** «нет пересечений рёбер вне общих узлов».

## Реализовано

- `GridForestPlanner.repairCrossings` вызывается в `refineTrees` после ремонта
  поворотов: ищет пары рёбер без общих узлов с пересечением, выбирает «жертву»
  (меньшее по длине) и перепрокладывает её через `gridPath`, добавляя остальные
  рёбра дерева временными препятствиями (`ObstacleIndex.withAdditional`) с
  вырезами (3 м) вокруг узлов. При неудаче — `FOREST_CROSSING_UNRESOLVED`.
- `RouteCrossingResolver` (для `mst`) не используется.
- **E27-05.** `repairGlobalCrossings`: после уточнения всех деревьев выполняется
  общий проход — пересечения рёбер **разных** деревьев разрешаются тем же
  `gridPath`, где препятствиями служат рёбра всех деревьев, а вокруг всех узлов
  делаются вырезы.
- **E27-06.** `SpecialSpanSplitter` не выпрямляет спецучасток хордой, если она
  пересекает другое ребро нового леса (`SPECIAL_STRAIGHTEN_CROSSING`).
- Инвариант «0 самопересечений» проверяется на основном наборе
  (`GridForestInvariantsSlowTest`) и на наборе E29 (`SpecialRoutingExperimentTest`):
  в дефолтном (strict) и combined-режимах пересечений нет (0).

## Следствия

- Инвариант FR-29 гарантируется единообразно с остальной геометрией сетки.
- Реализация использует уже существующий grid-поиск; рост объёма кода
  `GridForestPlanner` компенсируется отсутствием второго геометрического
  резолвера.
- Возможны итерации «перепроложить → проверить углы/степень → перепроложить».
