# ADR-0013. Опциональный фронтенд-визуализатор

- Статус: accepted
- Дата: 2026-09-16

## Контекст

Протокол встречи 16.09.2026: UI не требуется, качество визуализации не
оценивается, отдельный контейнер фронтенда не обязателен. При этом команде
нужен инструмент для проверки и демонстрации результатов (визуализация трасс
и ключевых параметров, влияющих на решение о реализации).

## Решение

Ядро остаётся headless (ADR-0010). Дополнительно создаётся **опциональный
визуализатор** — отдельное SPA, не входящее в оцениваемую поставку:

- стек: React 18 + TypeScript + Vite + Mantine v7;
- карта: MapLibre GL JS; офлайн-подложка через локальный PMTiles
  (Protomaps), с нейтральным стилем-фолбэком и локальными глифами;
- состояние: TanStack Query (серверное) + Zustand (UI);
- контейнер — отдельный сервис compose с профилем `frontend`
  (`docker compose --profile frontend up`), по умолчанию не поднимается.

Визуализатор читает результат either из API, either из локального GeoJSON
(работает без backend). Сервис API не меняется.

## Следствия

- Положительные: инструмент проверки/демонстрации без влияния на оцениваемую
  headless-поставку; переиспользует публичный API.
- Отрицательные: дополнительный стек и поддержка; офлайн-подложка требует
  подготовки PMTiles и глифов; риск случайного «протаскивания» UI в ядро —
  контролируется правилами AGENTS.md.
