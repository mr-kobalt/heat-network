# ADR-0010. Headless-сервис без UI

- Статус: accepted
- Дата: 2026-09-16

## Контекст

Протокол встречи 16.09.2026: UI не нужен; оценивается чистый сервис
«входные данные → выходной GeoJSON». Качество визуализации не оценивается,
важна корректность GeoJSON. Отдельный контейнер фронтенда не обязателен.

## Решение

Не разрабатывать пользовательский интерфейс и не включать фронтенд в
docker-compose. Сервис предоставляет REST API, документацию Swagger
(желательна) и выгрузку файла результата. Вся визуализация — на стороне
пользователя (внешние ГИС), вне обязательств сервиса.

## Следствия

- Положительные: меньше объёма работ, фокус на корректности GeoJSON и расчёта.
- Отрицательные: демонстрация требует внешнего просмотрщика GeoJSON;
  сопроводительная документация API становится важнее.
