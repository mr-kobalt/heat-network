# ADR-0001. Обязательный технологический стек

- Статус: accepted
- Дата: 2026-09-16

## Контекст

Требования конкурса жёстко фиксируют платформу (PDF 3.2). Отклонение
исключает участие.

## Решение

Принять обязательный стек без изменений:

- Ubuntu Server 22;
- Java 11;
- `spring-boot-starter-parent` 2.6.3;
- PostgreSQL ≤ 18 или OpenSearch ≤ 2.18;
- `springdoc-openapi-ui` 1.7.0;
- docker-compose 1.29.2.

LTS-версии зафиксированы в `pom.xml` (`java.version=11`) и в devenv
(`pkgs.jdk11`).

## Следствия

- Положительные: соответствие требованиям, воспроизводимость.
- Отрицательные: устаревший стек, часть библиотек недоступна; требуется
  подбор совместимых версий зависимостей.
