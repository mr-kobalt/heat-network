# ADR-0044. Перестройка дерева в relink (перенос узлов с поддеревом)

- Статус: accepted
- Дата: 2026-09-22

## Контекст

`relink` оптимизировал только терминальные листья: перебирал врезки для точек
подключения и не мог перестроить промежуточную часть дерева (стволы,
промежуточные камеры). Из-за этого оставались неоптимальные обходы и лишние
камеры.

## Решение

За флагом `forest-relink-nodes` (default **false**) relink дополнительно
переносит **любой не-корневой узел вместе с поддеревом**:

1. Для узла `R` строятся `parent`-карта от корня и `subtree(R)`.
2. Кандидаты присоединения в радиусе `forest-relink-nodes-radius-m` (default
   100 м):
   - существующие **не-терминальные** узлы вне `subtree(R)`;
   - T-точки на рёбрах вне `subtree(R)` (сплит ребра + новый узел-камера).
3. Геометрия ветки — прямая `[C, R]`; углы маршрута чинит `refine` (ADR-0043).
4. Удаляется родительское ребро, добавляется ветка; дерево пересобирается
   (`rebuild`), применяется строго лучшее по `S`.
5. Гейты: валидное дерево; **степень каждого узла ≤
   `forest-max-chamber-degree`** (default 4, FR-26; ветвления только в камерах
   обеспечиваются типизацией `rebuild`); запреты и самопересечения (как в
   `validSegment`); терминалы — листья, корень не перемещается.
6. Проходы — `forest-reattach-iterations`; прунинг удаляет осиротевшие цепочки
   (в т.ч. при переносе на предка).

Контроль степени FR-26 применяется во всех проверках relink (в т.ч. при
переносе терминалов), поэтому baseline немного изменился и при выключенном
флаге.

## Следствия

- Дефолт (флаг выключен): `S` 14.051996 → **14.051205**, длина 2034.214 →
  2034.071 м, стоимость 283.906 → 283.893 млн (эффект контроля степени).
- Флаг включён (эксперимент `RelinkNodesExperimentTest`): `S` **13.351**,
  длина 1893.5 м, стоимость 274.0 млн, камеры 55 млн, поворотов >90 — 3
  (≤6), `unconnected=0`.
- Затрагивает `TerminalRelinker` (`bestForNode`, `parentMap`, `subtreeNodes`,
  `degreeWithinLimit`), `AppProperties`/`application.yml`, тесты
  (`RelinkNodesTest`, `RelinkNodesExperimentTest`), baseline slow.
- Ограничение: перебор `узлы × кандидаты` в радиусе; при необходимости
  ограничивается радиусом/топ-N. Пересечения после переносов — ADR-0045.
