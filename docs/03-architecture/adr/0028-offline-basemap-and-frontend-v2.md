# ADR-0028. Офлайн-карта региона и соответствие визуализатора ТП v2

- Статус: accepted
- Дата: 2026-09-20

## Контекст

Опциональный визуализатор (ADR-0013) использовал нейтральный фон и типы
вывода прежней редакции ТП. Требуется: показывать входные данные вместе с
результатом, давать панель параметров объекта, выбирать алгоритм трассировки,
работать на локальной карте Москвы и Московской области **без интернета** и
иметь управление масштабом со сбросом на все объекты.

## Решение

1. **Соответствие ТП v2.** Типы и слои приведены к v2: вывод — только
   `heat_network`, `heat_chamber`, `technical_node`, `variant_summary` (без
   `tie_in` и реконструкции); сводка — `construction_cost`,
   `chamber_construction_cost`, `existing_chamber_tie_in_count/cost`,
   `unconnected_penalty`, `calculated_cost`, `new_network_length`, `score`;
   спецпроходы — по таблице 2 (`railway` — запрет).
2. **Вход + результат.** При запуске через API параллельно с результатом
   загружается и отображается исходный GeoJSON (ОКС, существующая сеть,
   ограничения); авто-подгонка вида учитывает оба набора.
3. **Правая панель.** Параметры выбранного объекта выводятся в
   `AppShell.Aside` справа (клик по объекту на карте).
4. **Выбор алгоритма.** `Select` в панели данных, список — `GET
   /api/v1/algorithms`; выбранный id передаётся в `POST .../runs?algorithm=`
   (ADR-0027).
5. **Локальная карта.** PMTiles-экстракт Protomaps (OSM, ODbL) + локальные
   глифы. В репозиторий коммитятся стиль, глифы и грубый
   `placeholder.pmtiles`; полный `moscow.pmtiles` (z≤14, Москва + область)
   готовится скриптом `scripts/fetch-basemap.sh` и не коммитится.
   `resolveBasemapStyle()` выбирает стиль по наличию файла, с фолбэком на
   нейтральный фон. Атрибуция OSM/Protomaps включена.
6. **Масштаб.** Свои кнопки «+», «−», «Показать все» (fit по input+result);
   `ScaleControl` сохранён.

## Следствия

- Положительные: карта и подписи работают офлайн; видно входной контекст;
  выбор алгоритма доступен из UI; доказательство концепции для полной карты —
  одним скриптом.
- Отрицательные: полный экстракт z14 большой (десятки–сотни МБ) и требует
  однократной загрузки; в чистом клоне доступен только placeholder.
- Подложка — не геодезический эталон: расхождения контуров набора и OSM в
  1–3 м нормальны и не корректируются (A-19).
- Оценка: изменения вне оцениваемой поставки (фронтенд опционален, ADR-0013);
  headless-ядро и контракт GeoJSON не затронуты.
