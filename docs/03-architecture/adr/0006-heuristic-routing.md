# ADR-0006. Эвристический конвейер маршрутизации

- Статус: accepted
- Дата: 2026-09-16

## Контекст

Задача — ограниченный лес Штейнера с нелинейной стоимостью от потока,
предельными длинами, степенью камер ≤4 и препятствиями. Точное решение
(NP-сложная задача) не укладывается в ресурсы (16 ГБ, 3 ГБ вход, 50
пользователей) и время.

## Решение

Построить многоэтапный эвристический конвейер:
подготовка → модель препятствий → кандидаты → граф видимости +
A*/Dijkstra → кластеризация точек → слияние стволов → расход/Ду/предельная
длина → стоимость → варианты (реконструкция исключена ТП v2, ADR-0021). Подбор
Ду, длины, стоимость — точные детерминированные функции. Детерминированный seed.

Детали — в [algorithm.md](../algorithm.md).

## Следствия

- Положительные: приемлемое время, объяснимость, возможность выдавать варианты.
- Отрицательные: нет гарантии глобального оптимума; требуется постобработка
  геометрии и проверки правил; качество зависит от эвристик.
