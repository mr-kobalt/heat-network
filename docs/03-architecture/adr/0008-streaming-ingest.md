# ADR-0008. Потоковый ввод/вывод GeoJSON

- Статус: accepted
- Дата: 2026-09-16

## Контекст

Требуется принимать файл до 3 ГБ и выгружать до 500 МБ, не загружая целиком
в ОЗУ (PDF 3.2). ОЗУ ограничено 16 ГБ.

## Решение

Использовать потоковый разбор GeoJSON (Jackson streaming API) с записью
промежуточных результатов во временное дисковое хранилище и обработкой
батчами. Парсер классифицирует объекты по `object_type`, не удерживая весь
документ в памяти. Для выгрузки — потоковая запись GeoJSON.

## Следствия

- Положительные: соответствие требованию, устойчивость на больших наборах.
- Отрицательные: сложнее код и валидация; нельзя использовать целиком
  объектную модель входного файла в памяти; геометрию обрабатывать
  по частям/кластерам.
