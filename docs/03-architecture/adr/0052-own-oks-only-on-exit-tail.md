# ADR-0052. Свой ОКС запрещён вне финального хвоста выхода

- Статус: accepted
- Дата: 2026-09-25
- Контекст: FR-29/FR-32, ТП 2.2, ADR-0024/0032/0040/0043

## Контекст

Канонический выход ОКС (`ConnectionExit`) — перпендикуляр к внешней границе
буфера своего ОКС, продолженный до `target`; хвост `tail = [target, point]`
заведомо пересекает буфер своего ОКС (точка подключения внутри полигона).

При реализации `grid-forest` множество препятствий, содержащих точку
подключения (`ownObstacles`), передавалось как «игнорируемое» на **всё**
терминальное ребро: в `simplifyEdges`, `repairNodeTurns`/`repairEdgeTurns`,
`repairCrossings`/`rebuildCrossing`, `repairExitApproach`, `TerminalRelinker`
и `optimizeChambers`. Из-за этого ствол маршрута мог быть спрямлён через
собственное здание: на наборе OSM `e_1_0_40` (точка 10) заходил в буфер, а
`e_3_0_42` (точка 16) — в собственный ОКС; корневые стыки (`ch_2`, точка 17)
также могли прокладываться через свой ОКС.

## Решение

Игнорировать свой ОКС разрешено **только на отрезке `target→point`** (и в
самой точке `point`). Любой другой отрезок терминального ребра проверяется по
своему ОКС как по обычному препятствию.

- `TerminalRelinker.validSegment`: ствол `кандидат→target` проверяется без
  изоляции; канонический хвост добавляется отдельно (`branch`).
- `GridForestPlanner.rebuildCrossing`: терминальный хвост сохраняется отдельно,
  по сетке перепрокладывается только ствол до `target`.
- `repairExitApproach`: перепрокладывается ствол до `target`; хвост
  добавляется без проверки.
- `simplifyEdges`, `repairEdgeTurns`/`removeMicroVertices`, `optimizeChambers.stub`:
  своя изоляция не применяется (функции не трогают последние две вершины —
  `target`, `point`).
- Маска проходимости роста и так блокирует свой ОКС; принудительно открываются
  только клетка `target` и коридор хвоста (`addCorridorCells`).

## Следствия

- Положительные: ствол не проходит через свой ОКС; инвариант
  `assertNoOksCrossingBeyondApproach` выполняется для всех вариантов на основном
  и OSM-наборах. Длина/`S` растут (обход зданий): основной набор
  `S` 13.2279 → 13.5598, длина 1859.8 → 1911.9 м; OSM `S` 13.4463 → 13.8057.
  Все точки подключены (0 неподключённых).
- Отрицательные/ограничения: маршрут может стать длиннее прямого; в стеснённых
  случаях ремонт стыка (`repairExitApproach`) может не найти путь — тогда
  остаётся диагностика `FOREST_TURN_UNRESOLVED`/`FOREST_CROSSING_UNRESOLVED`.
- Затрагивает `GridForestPlanner`, `TerminalRelinker`, тесты
  (`VerificationHarnessTest`, `GridForestInvariantsSlowTest`,
  `GridForestOsmInvariantsSlowTest`, `CalculationPipelineSlowTest` baseline),
  `docs`.
