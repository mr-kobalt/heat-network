# ADR-0041. Гексагональная сетка поиска пути

- Статус: accepted
- Дата: 2026-09-22

## Контекст

Поиск пути `grid-forest` (ADR-0034) использует квадратную сетку и 8-соседство.
Диагональные шаги жёстко привязаны к осям (0°/45°/90°), из-за чего трассы на
косой геометрии получают «лесенки» и лишние повороты, а узкие проходы,
расположенные под углом, хуже проходятся. После ADR-0040 (фильтрация выходов)
часть точек могла стать `blocked`, если короткого допустимого выхода не было —
сетка, лучше работающая в стеснённых местах, снижает эту потребность.

## Решение

Ввести форму сетки `GridShape` (ADR-0041) с двумя реализациями:
`SquareGridShape` (прежняя) и `HexGridShape` (pointy-top, odd-r смещение).
Гекс даёт 6 равных направлений; соседи по рёбрам, «диагонального» проскока нет.

1. **Флаг** `forest-grid-shape=square|hex`, дефолт — **hex** (по результатам A/B).
2. **Центры/индексация:** клетки по-прежнему в матрице `row * width + col`;
   гекс-центр `x = origin + (col + 0.5 + (row&1)/2)·cell`,
   `y = origin + (row + 0.5)·cell·√3/2`; шаг соседей равен `cell`
   (circumradius `cell/√3`), вертикальный шаг строк `cell·√3/2`.
3. `ObstacleMask` делегирует форму (`cellAt`, `neighbors`, `stepLength`,
   `diagonalStep`, `rowSpacing`, `shapeId`); `ObstacleMaskBuilder` растеризует
   центры со сдвигом строк. `GridForestPlanner` считает углы поворота по
   координатам центров (универсально для обеих сеток), длины — по `stepLength`,
   поиск ближайшей свободной клетки — BFS по соседям (для квадрата сохранён
   прежний кольцевой скан, чтобы поведение не менялось).
4. **Трасса:** в `grid.json` добавлены `gridShape` и `rowSpacing`;
   визуализатор рисует маску запретов/достижимости **шестиугольниками**
   (canvas-изображение, pointy-top, со сдвигом строк), а контуры ячеек при
   достаточном зуме — гекс-полигонами.
5. **Оценка числа клеток** для решения о спилле считается через
   `GridShape.columns/rows` (учитывает вертикальный шаг hex).

## Следствия

- Положительные (A/B на реальном наборе): `S` 13.099 → 12.973, длина
  1863.7 → 1836.5 м, стоимость 268.1 → 266.5 млн, углов >90° в выводе 4 → 0
  (внутренних 2 → 0), пересечений нет, консолидация 3/6/8 на одной камере
  сохранена; в A/B гекс оказался и быстрее (≈4.8 против 7.0 с). Камер 13 → 14
  (небольшой рост стоимости камер). Квадратная сетка остаётся доступной флагом.
- Отрицательные: заметный рефакторинг сетки (маска, планировщик, трасса,
  фронтенд); `forest-grid-cell-m` для гекса задаёт расстояние между центрами
  соседей, т.е. площадь клетки меньше квадратной (≈3.46 против 4 м²) — размеры
  матрицы меняются.
- Затрагивает `GridShape`/`SquareGridShape`/`HexGridShape`, `ObstacleMask`,
  `ObstacleMaskBuilder`, `GridForestPlanner`, `GridMaskPayload`,
  `StageTraceWriter`, `AppProperties`, фронтенд (`gridMask`/`stageLayers`,
  `types`), тесты; `OksApproachResolver`/`TerminalRelinker` без изменений.
