# ADR-0004. JTS для вычислительной геометрии

- Статус: accepted
- Дата: 2026-09-16

## Контекст

Требуются буферы, пересечения, расстояния, граф видимости, пространственные
индексы в метрической СК (EPSG:32637). Нужна библиотека, совместимая с Java 11
и не тянущая тяжёлый ГИС-стек.

## Решение

Использовать `org.locationtech.jts:jts-core` для геометрических операций
в приложении. Преобразование CRS выполнять отдельным шагом (локально или
средствами PostGIS), не смешивая с JTS.

## Следствия

- Положительные: лёгкая, зрелая библиотека; полностью Java 11-совместима.
- Отрицательные: JTS не выполняет перепроецирование — CRS-трансформацию нужно
  реализовать/подключить отдельно; возможна частичная зависимость от PostGIS.
