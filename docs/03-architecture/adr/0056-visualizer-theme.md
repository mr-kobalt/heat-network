# ADR-0056. Оформление визуализатора: тема Mantine, иконки и локальный шрифт

- Статус: accepted
- Дата: 2026-09-25
- Контекст: ADR-0013, ADR-0028, ADR-0029

## Контекст

Визуализатор построен на Mantine v7 (ADR-0028). Интерфейс использовал
настройки темы по умолчанию и текстовые подписи; требовалось сделать оформление
современнее (крупная типографика, символы) без перегруза и без смены стека.
Ключевое ограничение — офлайн-режим (ADR-0012): нельзя тянуть шрифты и иконки с
внешних CDN в рантайме.

## Решение

Остаться на Mantine и задать единую тему:

1. **Тема `createTheme`** (`frontend/src/theme.ts`): типографика Inter, крупная
   шкала `fontSizes`/`headings`, единый `defaultRadius`, акцент `indigo`.
2. **Шрифт локально** — `@fontsource/inter` (400/500/600/700) подключается в
   бандл; внешние CDN не используются.
3. **Иконки** — `@tabler/icons-react` (офлайн-пакет) во вкладках левой панели,
   списке этапов и легенде.
4. **Умеренность.** Структура и состав компонентов сохраняются; меняются
   настройки темы, символы и акценты, а не переработка UX.

Переезд на shadcn/ui + Tailwind рассмотрен и отклонён: требует переписать все
компоненты и удалить Mantine ради визуального эффекта — несоразмерно риску и
объёму для опционального визуализатора вне оцениваемой поставки (ADR-0013).

## Следствия

- Положительные: единый современный вид без смены стека; шрифт и иконки
  работают офлайн; минимум изменений в компонентах.
- Отрицательные: +2 зависимости фронтенда; вес бандла шрифта (кириллица/латиница
  в нескольких начертаниях).
- Затрагивает `frontend/src/theme.ts`, `main.tsx`, `App.tsx`,
  `components/StagePanel.tsx`, `package.json`.
