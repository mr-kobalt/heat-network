# ADR-0002. Maven как инструмент сборки

- Статус: accepted
- Дата: 2026-09-16

## Контекст

Требование задаёт `spring-boot-starter-parent` 2.6.3 — это Maven-родитель.
У команды нет опыта в Java, нужен предсказуемый стандартный инструмент.

## Решение

Использовать Maven и `spring-boot-starter-parent` 2.6.3. Версию Java задавать
свойством `java.version`. Не вводить Gradle.

## Следствия

- Положительные: прямое соответствие требованию, много документации и примеров,
  генерация Docker-образа через `spring-boot-maven-plugin`.
- Отрицательные: многословный `pom.xml`; Maven-конфигурация должна оставаться
  простой.
