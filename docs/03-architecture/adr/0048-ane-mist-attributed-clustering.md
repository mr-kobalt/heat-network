# ADR-0048. ANE-MiST (атрибутная кластеризация): отклонено

- Статус: rejected
- Дата: 2026-09-24

## Контекст

Рассматривалась статья ANE-MiST — Attributed Network Embedding with Minimum
Spanning Tree for Optimizing Water Pipe Network Layouts
(https://ieeexplore.ieee.org/document/11195111). Идея: атрибутное вложение
узлов (структурная близость + близость атрибутов), кластеризация и
реконструкция раскладки через MST.

Проверялась гипотеза: применить атрибутную кластеризацию точек подключения к
задаче ЛЦТ 2026 — дать `grid-forest` дополнительные содержательно отличающиеся
варианты (FR-75), не ухудшая лучший `S`.

## Что рассматривалось

1. Спайк: `AneNode` (точка ОКС/кандидат врезки), `AttributedGraphBuilder`
   (`W_S` kNN+RBF, `W_A` косинус), спектральное вложение (нормированные
   лапласианы + консенсус через SVD), детерминированный k-means.
2. Алгоритм `grid-forest-ane`: базовый план `grid-forest` плюс кластерные
   варианты — точки разбиваются на атрибутные кластеры (`k∈{2,3}`), и
   `GridForestPlanner` прогоняется по каждому кластеру отдельно.
3. Зависимость `org.apache.commons:commons-math3:3.6.1` для собственных
   разложений/SVD/k-means.

## Решение

Отклонено. Код и зависимость удалены.

Причины:
- **Варианты бессмысленны.** Кластерные леса не дают практически ценной
  альтернативы: лучший `S` не улучшается, а сами варианты — механическое
  следствие разбиения, без выигрыша для конкурсной оценки.
- **Модель не учитывает главное.** У ANE нет препятствий, стоимости и правил
  прокладки, а `grid-forest` их уже учитывает; дополнительной информации
  вложение не приносит.
- **Цена/сложность.** Несколько прогонов сетки; внешняя зависимость;
  усложнение конвейера и тестов без измеримой пользы.

## Следствия

- Дефолт (`grid-forest`) и `mst` не затрагиваются; новых зависимостей нет.
- Подключаемая абстракция кластеризации и пакет `routing.ane` не вводятся.
- Статья остаётся справочным материалом (ссылка выше); при пересмотре решения
  требуется новый ADR.
