# ADR-0029. Условные обозначения, компас и зоны ограничений в визуализаторе

- Статус: accepted
- Дата: 2026-09-20

## Контекст

Визуализатор (ADR-0013, ADR-0028) показывал объекты однотипными кругами и
линиями без различия типов и диаметров; панель «Слои» не содержала условных
обозначений и не позволяла оценить минимальные горизонтальные расстояния из
таблицы 2 ТП v2. На карте нельзя было вернуть ориентацию после поворота,
а подключаемые ОКС визуально не отличались от прочих ограничений.

## Решение

1. **Компас.** В `FitZoomControl`, под кнопками масштаба, кнопка-компас видна
   только при повороте карты (`bearing ≠ 0`). Клик сохраняет пользовательскую
   ориентацию и ставит север сверху (`setBearing(0)`); повторный клик
   возвращает сохранённое значение. Указатель — двухцветный ромб (северная
   половина красная, южная светлая), поворачивается на `-bearing`.
2. **Цвето-фигурная дифференциация.**
   - тепловые камеры — квадрат с точкой (symbol-иконка, существующие — серые,
     новые — зелёные);
   - технические узлы — полый круг;
   - трубы — толщина и оттенок по `diameter`; новая сеть — цветная шкала,
     существующая сеть — серая шкала;
   - ОКС-полигон с точкой подключения внутри — отдельный цвет (point-in-polygon),
     прочие ОКС и ограничения — приглушённые/по таблице 2;
   - точки подключения — три состояния: подключена, не подключена
     (`variant_summary.unconnected_oks_ids` активного варианта), результат не
     загружен.
3. **Слои и легенда.** Панель «Слои» показывает чекбокс с мини-иконкой в цвете
   объекта; для труб — кнопка «?» с подсказкой «цвет/толщина ↔ Ду»; отдельный
   переключатель «Зоны мин. расстояний».
4. **Зоны минимальных горизонтальных расстояний.** Строятся в метрах через
   `@turf/buffer` (метры, не пиксели) на основе карты `restriction_type → м`
   из таблицы 2 (`restrictions.ts`); по умолчанию скрыты. Для ОКС принято
   минимальное значение 5 м (Ду примыкающего участка по полигону неоднозначен).
5. **Обводка полигонов.** Все полигональные объекты (ограничения и зоны) имеют
   контур того же цвета, что заливка, без прозрачности; заливка остаётся
   полупрозрачной.
6. **Подсветка кликабельных объектов.** Источники создаются с `generateId`;
   при наведении курсор становится указателем, а объект подсвечивается через
   `feature-state.hover` (утолщение линий/контуров, рост точек и иконок,
   усиление заливки).
7. **Обесцвеченная подложка.** Локальные стили генерируются флейвором
   `grayscale` (вместо `light`), чтобы OSM не конкурировала с объектами
   трассировки.
8. **Отключение подложки.** Слои OSM (кроме нейтрального `background`)
   управляются тумблером «Подложка OSM»; оверлеи при этом не пересоздаются.
9. **Кнопка «?».** В легенде вынесена из `label` чекбокса — открытие подсказки
   не переключает видимость слоя.
10. **Попап вместо правой панели.** Параметры объекта показываются в
    `maplibregl.Popup` в точке клика (`select(feature, anchor)`), а не в
    `AppShell.Aside`; контент рендерится порталом (`createPortal`) в основном
    React-дереве — иначе попап остаётся пустым. Клик по пустому месту закрывает
    попап.
11. **Зоны мин. расстояний.** Красная диагональная штриховка (`fill-pattern`
    из локального тайла, `fill-opacity ≈ 0.35`) и пунктирный контур `#dc2626` —
    без цветовой привязки к типу объекта. Для полигональных ограничений из
    буфера вычитается исходная геометрия (`@turf/difference`), чтобы залить
    только кайму по краям, а не сам объект.
12. **Фон без подложки.** При отключённой подложке цвет слоя `background`
    принудительно `#ffffff`, при включённой — исходный.
13. **Ширина левой панели.** Перетаскивается мышью (240…640 px, сохраняется в
    `localStorage`); ручка — разделитель на границе панели.
14. **Viridis и ширина.** Цвет — viridis по Ду (новая сеть) и viridis в
    чёрно-белом исполнении (существующая; тёмный — больше Ду). Ширина по
    умолчанию пропорциональна Ду; переключатель «Реальный масштаб труб» в
    панели «Слои» переводит ширину в реальную ширину пары по таблице 1 ТП v2
    (0,40…3,45 м) с учётом зума (нижний порог `MIN_PIPE_WIDTH_PX` — для
    кликабельности).

## Следствия

- Положительные: визуальная проверка вариантов и близости к ограничениям;
  легенда объясняет обозначения; ориентация карты управляема.
- Отрицательные: новая зависимость `@turf/buffer` (+ `@turf/helpers`) в
  визуализаторе; размер бандла растёт. Расстояния зон — визуальная оценка и не
  заменяют расчёт ядра.
- Оценка: изменения вне оцениваемой поставки (фронтенд опционален, ADR-0013);
  headless-ядро и контракт GeoJSON не затронуты.
