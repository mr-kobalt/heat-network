# ADR-0070. Кластерный junction-центроид (два механизма, выбор по A/B)

- Статус: proposed (оба механизма по умолчанию **выключены**; выбор — по A/B)
- Дата: 2026-09-29
- Контекст: FR-23 (общие стволы), FR-25/FR-26 (камеры, степень ≤4); разбор
  решения команды 8 (`case-02-heat-network-routing-team-8`, `planOneCluster`),
  задачи E58-02a/b

## Контекст

Для близких ОКС команда 8 строит общий ствол: junction = среднее координат
выходов кластера (при `pointBlocked` — ближайший незаблокированный выход), один
ствол до сети, отводы ОКС → junction.

В `grid-forest` общий ствол возникает неявно (T-врезки терминалов,
`mergeChambers`); отдельного кластерного узла нет. На плотных группах это может
давать лишнюю длину и камеры. Проверяются **два независимых механизма** под
раздельными флагами; допускается совместная проверка.

## Решение

### Вариант A — кластерный junction (`forest-cluster-junction`, дефолт off)

Для точек, сгруппированных по `forest-cluster-radius-m`, junction = центроид их
выходов; при `pointBlocked` — ближайший свободный выход. Ствол прокладывается к
сети, отводы ОКС — к junction; степень камер ≤ `forest-max-chamber-degree`
(FR-26).

### Вариант B — центроид при слиянии камер (`forest-chamber-merge-centroid`, дефолт off)

В `mergeChambers` (E50-05) позиция объединённой камеры — центроид выходов
участников с fallback на незаблокированную точку (вместо взвешенной медианы
стыков, ADR-0051). Топология поиска не меняется — локальное изменение положения
камер.

Выбор механизма(ов) — по итогам A/B (E58-03); проигравший удаляется, baseline
пересчитывается только для принятого.

## Следствия

- Положительные: меньше `L`/`C` у плотных групп; явная альтернатива неявному
  общему стволу.
- Отрицательные/ограничения: A может сменить канонический выход (FR-43/E43) и
  углы; B — локально менять положение камер. При отсутствии выигрыша механизм
  помечается `rejected` (образец ADR-0060/0061).
- Верификация: A/B `S`/`L`/`C`/степень/FR-29 на основном и OSM-наборах;
  `exitMismatches=0`; fast+slow зелёные.
- Затрагивает: `routing/GridForestPlanner` (`plan`, `mergeChambers`),
  `config/AppProperties`/`application.yml`, тесты, документацию.

## Связанное

- Задачи: E58-02a (вариант A), E58-02b (вариант B), E58-03 (A/B и решение).
