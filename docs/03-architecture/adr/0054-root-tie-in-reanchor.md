# ADR-0054. Ре-привязка корня нового дерева с gridPath-фолбэком

- Статус: accepted
- Дата: 2026-09-25
- Контекст: ADR-0046 (E35), ADR-0051, ADR-0052

## Контекст

Корень нового дерева (новая камера присоединения к существующей сети)
выбирается ростом по сетке (meeting-point волн Дейкстры) и затем локально
оптимизируется в `optimizeChambers` (ADR-0051, E35 внутри стадии). Кандидаты
корня — текущая координата и **по одной проекции** медианы на каждый участок
сети, при этом:

- проекции не сортировались по расстоянию и обрезались до
  `forest-chamber-max-candidates` в порядке участков набора — ближайшая
  допустимая точка могла не попасть в рассмотрение;
- при заблокированном прямом стыке кандидат отклонялся без обхода по сетке
  (`gridPath`-фолбэк был только в legacy `optimizeRoot`).

При включённой изоляции своего ОКС (ADR-0052) прямой стык корня к ближайшей
проекции может быть запрещён, и нужен честный обход.

## Решение

1. Проекции корня сортируются по расстоянию до текущего положения и только
   затем обрезаются.
2. `tryChamberMove` получил параметры `pass` и `allowFallback`: при
   заблокированном прямом стыке и `allowFallback=true` (только корень) ствол
   строится через `gridPath(candidate → target, nextAfter=point)` с проверкой
   `Kспец`-углов; кандидат принимается только при строгом улучшении `S` после
   `MaxLengthEnforcer`.
3. Дешёвый префильтр: кандидат отбрасывается, если сумма прямых отрезков до
   соседей не короче текущего ствола (обход длиннее прямой).

## Следствия

- Положительные: корень перепривязывается к реально достижимой точке сети с
  учётом запретов; на наборе OSM для точки 17 (`rj_b_20000000_ch_2_41`) ближайшая
  по прямой точка сети блокирована собственным ОКС, и выбранный корень
  (~102 м по пути) близок к оптимальному обходу — улучшения относительно
  прямолинейной оценки нет, но решение теперь обосновано обходом, а не
  проигнорированным запретом.
- Отрицательные: для корня добавляется до `forest-chamber-max-candidates`
  вызовов `gridPath` на дерево (дороже ADR-0051, но затрагивает только корни).
- Затрагивает `GridForestPlanner` (`chamberCandidates`, `tryChamberMove`,
  `relocateChamber`), `docs`.
