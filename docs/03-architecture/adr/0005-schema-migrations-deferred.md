# ADR-0005. Миграции БД отложены

- Статус: accepted
- Дата: 2026-09-16

## Контекст

Spring Boot 2.6.3 управляет Flyway 8.x. Flyway 8 не поддерживает
PostgreSQL 18 (корректная работа с PG 18 требует существенно более новых
версий Flyway, которые, в свою очередь, требуют Java 17). Конфликт с
обязательным стеком.

## Решение

На старте не использовать Flyway и не выполнять автомиграции JPA
(`ddl-auto: none`). Схему добавлять осознанно и позже, после выбора
совместимого инструмента (например, отдельного управляемого SQL-скрипта
или иной версии PostgreSQL, поддерживаемой используемой версией Flyway).

## Следствия

- Положительные: приложение гарантированно стартует на PostgreSQL 18,
  меньше движущихся частей.
- Отрицательные: нет автоматического версионирования схемы; при появлении
  персистентных сущностей потребуется решение по миграциям. Решение
  пересмотреть отдельным ADR.
