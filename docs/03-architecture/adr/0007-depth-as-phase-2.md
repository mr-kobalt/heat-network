# ADR-0007. Глубина — отдельная фаза (Phase 2)

- Статус: accepted
- Дата: 2026-09-16

## Контекст

Дополнительная задача по глубине (2.5D) — самостоятельная: маршрут строится
заново с учётом вертикального положения. Она повышает сложность и не входит
в обязательную часть. Время конкурса ограничено.

## Решение

Сначала полностью реализовать обязательную 2D-часть (M1–M3). Глубину
проектировать и документировать сейчас, реализовывать после рабочей 2D-версии
(M4). Архитектура 2D-маршрутизации изначально допускает расширение состояния
узла глубиной.

## Следствия

- Положительные: снижение риска, приоритет обязательных требований.
- Отрицательные: 2D-алгоритм может потребовать доработки под 2.5D; часть
  правил (просветы, глубины коммуникаций) уже заложена в модель ограничений.
