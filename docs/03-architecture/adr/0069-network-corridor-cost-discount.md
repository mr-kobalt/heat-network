# ADR-0069. Cost-aware коридор вдоль существующей сети в `grid-forest`

- Статус: proposed (по умолчанию **выключено**; включается флагом после A/B)
- Дата: 2026-09-29
- Контекст: FR-23 (общие стволы), FR-76 (`S`); разбор решения команды 8
  (`case-02-heat-network-routing-team-8`, `GridPathfinder.stepCost`), задача E58-01

## Контекст

`grid-forest` ищет путь по растровой маске; вес шага — либо длина (проход 0),
либо вклад в `S` по оценке Ду (`costWeighted`, `GridForestPlanner` — блок
расчёта веса шага). Стоимость прокладки **вдоль существующей сети** в поиске не
отражается: маршрут одинаково «любит» свободное поле и коридор теплосети, хотя
общий ствол (FR-23) у сети короче и врезка ближе.

В решении команды 8 вес ребра умножается на `corridorCostFactor` (0.80) внутри
полосы `networkCorridorWidthM` (28 м) вокруг сети — это прижимает трассу к
существующей теплосети.

## Решение

Ввести опциональный **поисковый** множитель веса шага:

- если середина шага (или клетка) находится в полосе
  `forest-network-corridor-width-m` от существующей сети, вес шага умножается на
  `forest-network-corridor-cost-factor` (`0 < f ≤ 1`; `1.0` — no-op, дефолт);
- множитель применяется **только** к весу Dijkstra и не входит в
  `estimateScore` — честная оценка `S` остаётся прежней;
- near-network тест строится один раз на проход эффективно (растр/`STRtree` по
  сегментам сети); `TieInCandidateProvider.distanceToNetwork` (O(segments) на
  вызов) на горячий путь не годится;
- флаги — в `AppProperties`/`application.yml`; включается после A/B на основном
  и OSM-наборах.

## Следствия

- Положительные: потенциально ниже `L`/`C` за счёт прижатия трассы к сети;
  реализация дешёвая, изолирована флагом.
- Отрицательные/ограничения: меняет геометрию и baseline; может ухудшить углы
  (FR-34) или дать лишние изломы. При отсутствии устойчивого выигрыша —
  `rejected` по образцу ADR-0060/0061 (код, конфиг и тесты удаляются).
- Верификация: основной набор `S` 13.29925214746317, OSM 13.679614324110897;
  инварианты FR-29/34/26 = 0, канонический выход (FR-43/E43) сохранён; fast+slow
  зелёные.
- Затрагивает: `routing/GridForestPlanner`, `routing/TieInCandidateProvider`
  (near-network индекс), `config/AppProperties`/`application.yml`, тесты A/B,
  документацию.
