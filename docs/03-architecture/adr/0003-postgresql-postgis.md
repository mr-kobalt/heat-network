# ADR-0003. PostgreSQL + PostGIS

- Статус: accepted
- Дата: 2026-09-16

## Контекст

Требование допускает PostgreSQL ≤ 18 или OpenSearch ≤ 2.18. Задача —
геометрия, буферы, пересечения, пространственные индексы. Нужны надёжные
геометрические предикаты и работа с большими объёмами.

## Решение

Выбрать PostgreSQL с расширением PostGIS. Приложение использует JPA для
метаданных/расчётов; тяжёлые геометрические операции, при необходимости,
выполняются в PostGIS, а локальная геометрия — через JTS (ADR-0004).

## Следствия

- Положительные: зрелые пространственные индексы и функции, соответствие
  требованию, простое развёртывание (образ `docker.io/postgis/postgis`).
- Отрицательные: PostGIS — дополнительное расширение; сборка/образ должны его
  содержать. Миграции отложены (ADR-0005).
