# Открытые вопросы

Вопросы к организаторам кейса и решения, требующие уточнения. Статусы:
`open` — ждёт ответа, `resolved` — закрыт, `assumption` — принято допущение
(указано, где зафиксировано), `wontfix` — не влияет на реализацию.

> Часть вопросов закрыта протоколом встречи 16.09.2026 (см. `source/`).
> Новые вопросы из протокола (раздел «Незакрытые вопросы») добавлены как NQ-*.
