# Открытые вопросы

Вопросы к организаторам и решения, требующие уточнения. Статусы:
`open` — ждёт ответа, `resolved` — закрыт, `assumption` — принято допущение
(указано, где зафиксировано), `wontfix` — не влияет на реализацию.

> Источники: `source/Техническое  приложение ЛЦТ v2.docx` (ТП v2),
> `source/Разъяснения по вопросам ЛЦТ.docx` (разъяснения) и протокол
> встречи 16.09.2026. Приоритет: ТП v2 → разъяснения → протокол.

## 1. Ранее открытые вопросы

| Q-02 | Как обрабатывать `railway` | Спецпроход/запрет | resolved (ТП v2, таблица 2): пересечение запрещено, 1,0 м |

| Q-04 | Как задаётся место присоединения | Геометрия | resolved (ТП v2 2.4): только через камеру; ≤10 м и свободные примыкания → существующая, иначе новая; `tie_in` нет |
| Q-05 | Включаются ли спецучастки в `L` | Ранжирование | resolved (ТП v2 6): `L = new_network_length` (спецучастки — новые участки) |

| Q-09 | Представление спецучастка при наложении | Выход | resolved (ТП v2 4): max `Kспец`, без суммирования/перемножения, новый участок на границах |
| Q-10 | Ограничение длины отдельных сегментов | Геометрия | resolved (ТП v2 2.3): предельная длина по непрерывным путям; отдельного лимита сегмента нет |
| Q-11 | Как трактовать «ближайшую границу» для колодцев, П-форм и тесной застройки | Геометрия/стоимость | open: уточнить у организатора; реализовано допущение A-18 (ADR-0024) |

## 3. Допущения (v2)

| ID | Допущение | Где зафиксировано |
|----|-----------|-------------------|
| A-12 | Округление длин вверх при малом отклонении | [risks-and-assumptions.md](risks-and-assumptions.md), ADR-0018 |
| A-15 | Существующие примыкания камеры считаются по геометрии; проходная линия = 2 | ADR-0021, risks |
| A-16 | «Ближайшая граница» — проекция точки на контур `oks`-полигона | ADR-0023, risks |
| A-17 | Внутренний штраф за поворот (не стоимость) | ADR-0020, risks |
| A-18 | Для сложных форм и тесноты вывод к ОКС — ближайший допустимый перпендикуляр к внешней грани (или прямой выход из кармана), а не перенос ближайшей границы | ADR-0024, risks |
| A-19 | Строгий обход спецпроходов моделируется полосой с перфорированными «воротами» (шаг/ширина конфигурируемы); угол ≥45° обеспечивается перпендикулярностью ворот; полосы считаются по минимальному Ду | ADR-0045 |
| A-20 | В режиме глубины вертикальный зазор между габаритом новой сети и коммуникацией — `depth-vertical-clearance-m` (0,2 м); близкие пересечения (зазор ≤ `depth-close-crossing-m`, 5 м) объединяются без возврата на 3,0 м. ТП v2 чисел не задаёт | ADR-0073, calculation-rules §6.1 |
