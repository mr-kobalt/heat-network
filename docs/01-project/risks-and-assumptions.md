## 2. Допущения

- A-01. Цель — точка подключения ОКС; полигон ОКС (`restriction=oks`) не
  задаёт маршрут, но непроходим; для содержащего точку полигона — один
  финальный прямой участок (ТП 2.2).
- A-02. Топология по `upstream_object_id` не требуется; реконструкция не
  выполняется (ТП v2, разъяснение 14).
- A-03. `flow_tph` задан на точке подключения; каждая точка — самостоятельная
  цель (ТП 1.1).
- A-04. После преобразования в EPSG:32637 единица длины — метры.
- A-05. `restriction_type` соответствуют таблице 2 ТП v2; прочие — расширение.
- A-06. Все точки технически подключаемы; неполный результат — резервный
  сценарий; намеренное неподключение не допускается (разъяснение 15).
- A-07. Один источник; мощность не ограничивает.
- A-08. Геометрия существующей сети не проверяется; используется для выбора
  места присоединения.
- A-09. Локаль/часовой пояс не влияют; числа — double.
- A-10. Загрузка/выгрузка на одном сервере; сетевые ограничения не учитываются.
- A-11. Сервис офлайн, единственный экземпляр (протокол).
- A-12. Расстояния округляются в большую сторону при незначительном отклонении
  (протокол; ТП v2 молчит — допущение, допуск конфигурируемый).
- A-13. При наложении спецпроходов — максимальный `Kспец`, без суммирования и
  перемножения; на границах — новый участок (ТП 4).
- A-14. UI не требуется; корректность GeoJSON — ключевой показатель.
- A-15. Существующие примыкания камеры считаются по геометрии: каждый
  существующий участок, заканчивающийся в камере, — примыкание; проходная
  линия — 2 примыкания (разъяснение 12).
- A-16. «Ближайшая граница» `oks`-полигона — ближайшая точка контура полигона
  к целевой точке; финальный участок — прямой отрезок до неё (ТП 2.2). Для
  сложных форм (колодцы, П-формы) и тесной застройки применяется уточнение
  A-18.
- A-17. Внутренний штраф за поворот при маршрутизации не является стоимостью и
  служит только против зигзагов (ТП 2.1).
- A-18. Если перпендикуляр к ближайшей границе `oks` недопустим (упирается в ту
  же или соседнюю ОКС, ведёт в замкнутый карман) или ближайшая точка —
  вершина, точка стыковки выбирается как ближайший допустимый перпендикуляр к
  внешней грани (среди обращённых к сети), иначе — кратчайший прямой выход из
  кармана (ADR-0024). Требует подтверждения организатора (Q-11).
- A-19. Подложка карты (OSM/Protomaps) — справочный слой, не геодезический
  эталон. Расхождения контуров объектов набора и OSM в 1–3 м (генерализация
  контура/участка против точного контура здания, погрешность трассировки OSM)
  допустимы и не влияют на расчёт; координаты набора и результата не
  корректируются под OSM (ADR-0028).

## 3. Зависимости

- Проверочный набор — отдельные данные из рабочих систем (разъяснение 17).
- Актуальная версия правил — ТП v2; при расхождениях приоритет за v2 и
  разъяснениями.
- Уточнения — см. [open-questions.md](open-questions.md).
