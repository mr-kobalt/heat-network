# AGENTS.md

Краткая точка входа для AI-агентов. Подробности — в `docs/`.

## Проект

Сервис автоматического построения трасс подключения перспективных ОКС
к существующей тепловой сети (кейс ЛЦТ 2026). Вход и выход — GeoJSON.
Текущий этап: **M1** (рабочий прототип) и **M2** в редакции ТП v2
(обязательная 2D-задача: камера-присоединение, общие стволы, спецпроходы,
Ду+предельная длина по путям, до трёх вариантов и ранжирование). Реконструкция
исключена. Остаётся прогон на проверочном наборе; опциональный
фронтенд-визуализатор — вне оцениваемой поставки.

## Стек (обязательный, не менять без ADR)

Java 11 · Spring Boot 2.6.3 · Maven · PostgreSQL + PostGIS ·
springdoc-openapi-ui 1.7.0 · JTS · docker-compose. Ubuntu Server 22.

## Команды

Единый интерфейс — корневой `Makefile` (`make help`). devenv-скрипты и
`./mvnw` — обёртки; устанавливать nix не обязательно.

```bash
make help                          # список команд
make compile / build / test / verify
make test-slow                     # полный набор (slow)
make run                           # локальный запуск сервиса
make dev                           # БД + приложение + визуализатор (Ctrl+C — стоп)
make db-up / db-down / db-logs     # PostgreSQL + PostGIS (docker-compose)
make up / fe-up / stop / down / ps # Docker-стек (app+db, опц. frontend)
make compose-config                # если менялась инфраструктура
make fe-install / fe-dev / fe-build / fe-test
make deploy                        # развёртывание стека
./mvnw -B test                     # Maven Wrapper (без установленного Maven)
devenv shell / devenv test         # окружение nix (опционально)
pnpm --dir frontend basemap:prepare # локальная карта Москвы и области (PMTiles)
```

## Жёсткие правила

- Соблюдать требования **ТП v2**, а не прежний `source/data_example.geojson`;
  основной набор — `source/Датасет скорректированный.geojson`.
- Исходные материалы (ТЗ, ТП, датасет, протокол встречи) — в `source/`.
- Не хардкодить координаты, ID и конфигурацию набора.
- Потоковая обработка больших файлов (вход 3 ГБ, выход 500 МБ).
- Правила ограничений — конфигурируемые (ADR-0009).
- Не коммитить и не пушить без явного запроса.
- Архитектурные решения — через ADR; объём — через устав/дорожную карту.
- Перед завершением задачи: компиляция + тесты + обновление документации.
- Сервис headless (без UI); UI и фронтенд не добавлять в ядро (ADR-0010).
- Фронтенд в `frontend/` — опциональный визуализатор вне оцениваемой поставки (ADR-0013).
- Решение только на Java 11; расчёт офлайн, единственный экземпляр (ADR-0012).
- Каждый изменённый документ — с разделом «История изменений».
