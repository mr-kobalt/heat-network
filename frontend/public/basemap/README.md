# Офлайн-подложка (Москва + Московская область)

Визуализатор работает **без доступа в интернет**. Подложка — векторный
PMTiles-экстракт Protomaps (данные OpenStreetMap, лицензия ODbL; атрибуция
показывается на карте).

## Что коммитится

- `style.json` — стиль для полного экстракта `moscow.pmtiles`;
- `style-placeholder.json` — стиль для грубого `placeholder.pmtiles`;
- `placeholder.pmtiles` — грубый экстракт (z≤6), чтобы карта была не пустой
  без подготовки;
- `fonts/**` — локальные глифы (Noto Sans Regular/Medium/Italic) для подписей;
- `sprites/**` — локальный спрайт Protomaps (`light`) для иконок POI.

В стилях заданы `sprite`, локальные глифы и `maxzoom` источника (14 для
полного экстракта, 6 для placeholder): выше этого уровня MapLibre
масштабирует последний доступный тайл, а не запрашивает отсутствующие.

Полный `moscow.pmtiles` (z≤14) **не коммитится** (`.gitignore`), готовится
локально скриптом.

## Подготовка полной карты

```bash
pnpm --dir frontend basemap:prepare      # скачает CLI и извлечёт регион
```

Параметры через переменные окружения: `BBOX` (по умолчанию
`35.0,54.0,40.5,57.0`), `MAXZOOM` (по умолчанию 14), `PROTOMAPS_DATE`.

> z=14 для Москвы и области — большой экстракт (десятки–сотни МБ) и несколько
> минут загрузки. Для быстрой проверки оставьте placeholder или укажите
> `MAXZOOM=12`.

## Подложка «чертёжная бумага» (миллиметровка)

Нейтральная подложка без данных и сети: белый фон и сетка. Паттерн
`graph-paper` рисуется в `src/map/icons.ts` (`graphPaperPattern`) и
используется как `background-pattern` в `gridPaperStyle()` — тайлится в
экранных пикселях, поэтому шаг сетки не зависит от зума.

## Как выбирается стиль

`resolveBasemapStyle(id)` (`src/map/style.ts`) для `basemap: 'osm'|'grid'|'none'`:

- `osm`: `VITE_BASEMAP_STYLE_URL` → `moscow.pmtiles` (`style.json`) →
  `placeholder.pmtiles` (`style-placeholder.json`) → нейтральный фон;
- `grid`: `gridPaperStyle()` (миллиметровка, без сети);
- `none`: белый фон.

Стили OSM генерируются из `@protomaps/basemaps`:

```bash
pnpm --dir frontend basemap:style
```

## Управление картой и отладка

- Кнопки масштаба («+», «−», «Показать все») — нативный MapLibre-контрол
  (`src/map/controls.ts`); «Показать все» подгоняет вид под вход и результат.
- Отладочный режим: добавьте к адресу `?tiles=1` — включатся границы тайлов,
  лог ошибок тайлов и индикатор текущего зума в панели контролов.

> Подложка (OSM/Protomaps) — справочный слой, не геодезический эталон.
> Расхождения контуров объектов набора и OSM в 1–3 м нормальны (генерализация
> контура/участка против точного контура здания, погрешность трассировки OSM);
> координаты набора/результата под OSM не корректируются (A-19, ADR-0028).
