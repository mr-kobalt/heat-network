# Офлайн-подложка (PMTiles)

По умолчанию карта рисуется на нейтральном фоне (без внешних тайлов), что
соответствует офлайн-требованию. Для красивой подложки можно подключить
локальный PMTiles-экстракт.

## Как подключить

1. Получите PMTiles-экстракт нужного региона (один раз, при подготовке среды),
   например через утилиту `pmtiles` из Protomaps, и положите файл в эту папку:

   ```bash
   pmtiles extract https://build.protomaps.com/20240101.pmtiles \
     ./region.pmtiles --bbox=37.60,55.68,37.67,55.72
   ```

2. Подготовьте локальный style JSON, который ссылается на файл через
   `pmtiles://` и на локальные глифы (иначе подписи не работают офлайн).

3. Задайте переменную окружения при сборке/запуске:

   ```bash
   VITE_BASEMAP_STYLE_URL=/basemap/style.json
   ```

Файл `*.pmtiles`, как правило, большой и не коммитится (см. `.gitignore`).
Без него визуализатор полностью работоспособен — используется нейтральный фон.
